# Índice de Conhecimento Global

> Base de conhecimento transversal sobre inteligência artificial, arquitetura de software e segurança para qualquer tipo de projeto.

## Estrutura

```
knowledge/
├── global/          ← Conhecimento transversal e índice
│   └── INDEX.md
├── ai/              ← Inteligência Artificial e Roteamento
│   ├── AIJEV.md
│   ├── MODEL_SELECTION.md
│   └── AI_GATEWAY.md
├── architecture/    ← Padrões universais de arquitetura de software
│   └── PATTERNS.md
└── security/        ← Segurança de APIs e proteção de dados com IA
    └── OWASP.md
```

## Como Usar

- **Universal por Padrão**: As bases em `knowledge/` tratam de princípios fundamentais agnósticos a linguagens (Clean Architecture, Decision Gate, OWASP LLM).
- **Expansão Sob Demanda**: Conforme novos projetos em stacks específicas forem conectados, o desenvolvedor pode documentar decisões e aprendizados locais ou adicionar subpastas próprias.
- **Zero Ruído**: Cada arquivo é autocontido e livre de acoplamento a um projeto específico.
