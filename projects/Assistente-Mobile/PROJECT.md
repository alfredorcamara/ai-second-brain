# Assistente Mobile

## Visão Geral
Aplicativo mobile assistente pessoal com IA.

## Stack
- **Frontend**: .NET MAUI
- **Backend**: ASP.NET Core Web API
- **IA**: LLM para assistência, AIJev para decisões

## Objetivos
1. App mobile funcional com .NET MAUI
2. Backend API robusto
3. Integração com IA via AI Gateway
4. UX/UI premium
